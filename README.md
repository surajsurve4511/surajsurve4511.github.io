## ✨ Key Features

- **Futuristic Terminal UI**: Distinctive dark engineering theme featuring CRT scanline overlays, neon accent glow effects, and responsive navigation.
- **Zero Framework Overhead**: Built exclusively with pure HTML5, vanilla CSS3, and JavaScript — loads in under 300ms without bundler overhead or external JavaScript frameworks.
- **Interactive Micro-Interactions**: Real-time counter ticker animation on viewport intersection, typewriter heading, and smooth anchor scrolling.
- **Comprehensive Project Deep-Dives**: Detailed cards covering hardware robotics, autonomous aerial systems, generative AI assistants, and enterprise SaaS systems.
- **SEO & Social Open Graph Ready**: Pre-configured meta tags, Twitter card previews, and structured description tags.

## 🚀 Local Development & Preview

```bash
# 1. Navigate to the Portfolio directory
cd "/home/suraj/Suraj/MY_OS/Portfolio"

# 2. Open directly in any web browser
# On Linux:
xdg-open index.html

# On macOS:
open index.html

# On Windows:
start index.html

# Or serve via a lightweight HTTP server:
python -m http.server 8000
# Then visit http://localhost:8000
```
